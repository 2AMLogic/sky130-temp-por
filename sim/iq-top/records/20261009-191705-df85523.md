## Measurement definitions (exploratory; none is a ratified bound; no ceiling is proposed)
- **state definitions**: por-iq = RESETn asserted (low), directly simulated; iq-total = natural released state, directly simulated in its own run (never a sum); temp-iq = iq-total - por-iq, labelled incremental.
- **por-iq hold**: - RESETn is a DUT output (releases by itself above VPOR-rise), so the por-iq testbench (`testbench/tb_temp_por_iq_por.sch`) forces it low with a 0 V voltage source VRST from RESETn to VSS for the whole run. The DUT netlist is untouched. VRST's current is not part of the VDD measurement; the output stage's contention against it IS inside -i(BVDD) and is read as i(VRST).
- **measurement**: transient from a physical 0 V start, VDD = min(final, 1e4 V/s * t), held to 30 ms; I = -i(BVDD) time-averaged over the trailing 25-30 ms window.
- **settling**: ok only if trailing-window mean is within 1% of the 20-25 ms window mean, trailing pk-pk <= 2% of the mean, VDD within 5 mV of target, and the asked-for state holds (iq-total: RESETn > 0.8*VDD; por-iq: RESETn <= 50 mV). Otherwise `unsettled`.
- **non-physical-branch**: any saved node outside [-0.3 V, VDD+0.5 V] in the trailing window, settled total current <= 0, or a settled sub-cell current < -1 nA (the issue #19/#22/#86 signature documented in design/temp_core.md ~l.145-172). Applied identically in both states.
- **nonconverged**: klt/ngspice produced no waveform for the point, or the run ended before the trailing window.
- **attribution**: four 0 V ammeters in series with each sub-cell's VDD pin, inserted by the driver in the generated deck (electrically ideal; same deck both states).

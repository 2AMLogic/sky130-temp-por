## Predeclared comparison criterion (fixed before any result; see `experiment.json` `solver_sensitivity`)
- Two physical (`ok`) settled currents at the same corner AGREE iff |I_a - I_b| / min(I_a, I_b) <= 0.01 (1 %). A corner with >= 2 `ok` landings among {baseline, trtol7, reltol2e-4} AGREES iff the max pairwise relative difference is <= 0.01.
- Rationale: Fixed before any result was seen and independent of observed outcomes: 0.01 is the existing `settling.max_window_to_window_drift`, i.e. the repo's own definition of 'the same settled current' for one run; two solver settings that land on the same physical branch should reproduce a settled current at least as well as one run reproduces itself between adjacent windows. It is a measurement-equivalence band, not a spec limit. The smallest current is never selected and no variant is treated as authoritative.
